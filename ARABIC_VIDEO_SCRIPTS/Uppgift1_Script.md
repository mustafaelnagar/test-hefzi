## ما هي الفئة (Class)؟ (0:30 - 2:00)

الفئة ببساطة جداً هي مثل الرسمة أو المخطط:

**مثال من الحياة الواقعية:**
- الرسمة الهندسية = الفئة (Class)
- البيت المبني = الكائن (Object)

الفئة تعرّف الخصائص والسلوكيات، مثل:
- الخصائص: الاسم، اللون، الحجم
- السلوكيات: ماذا تفعل؟

**في برنامجنا:**
```
الفئة Person (شخص) فيها:
- خاصية: الاسم
- سلوك: تحية الشخص
```

## الكود - الجزء الأول (2:00 - 3:30)

```csharp
class Person
{
    public string Name { get; set; }
    
    public override string ToString()
    {
        return $"Hej! Jag heter {Name}";
    }
}
```

**شرح السطور:**

1. `class Person` - هنا ننشئ فئة باسم Person
2. `public string Name` - هذه خاصية للاسم
3. `{ get; set; }` - يعني يمكن قراءة الاسم وتعديله
4. `override string ToString()` - نستبدل الطريقة الأساسية بطريقتنا الخاصة
5. `return $"Hej! Jag heter {Name}"` - ترجع جملة تحتوي على الاسم

## الكود - البرنامج الرئيسي (3:30 - 5:00)

```csharp
static void Main()
{
    Person[] people = new Person[3];
    
    for (int i = 0; i < 3; i++)
    {
        Person p = new Person();
        p.Name = Console.ReadLine();
        people[i] = p;
    }
    
    foreach (Person p in people)
    {
        Console.WriteLine(p);
    }
}
```

**شرح خطوة بخطوة:**

1. `Person[] people = new Person[3]` 
   - نشئنا مصفوفة لحفظ 3 كائنات من نوع Person
   - Array = سلة يمكن فيها نضع 3 أشخاص

2. `for (int i = 0; i < 3; i++)`
   - حلقة تعيد 3 مرات (i = 0, 1, 2)
   - في كل مرة نقرأ اسم واحد

3. `Person p = new Person()`
   - new = كلمة حادة تعني: أنشئ كائن جديد
   - مثل: احضر شخص جديد

4. `p.Name = Console.ReadLine()`
   - نقرأ من المستخدم اسم
   - ونحفظه في خاصية Name

5. `foreach (Person p in people)`
   - حلقة تمر على كل شخص في المصفوفة

6. `Console.WriteLine(p)`
   - تطبع الشخص
   - تستدعي تلقائياً ToString()
